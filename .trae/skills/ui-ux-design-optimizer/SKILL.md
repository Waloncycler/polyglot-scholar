# UI/UX Design Optimizer

This skill provides guidelines and best practices for designing user-friendly, aesthetically pleasing, and efficient interfaces for academic and productivity tools.

## Core Design Philosophy: "Academic Immersion"

1.  **Zone-based Layout (分区管理)**:
    *   **Global Header**: Minimalist, only essential global actions (Settings).
    *   **Input Zone**: Dedicated toolbar for input actions (Import, Clear).
    *   **Command Center**: Centralized primary actions (Translate, Stop) to guide flow.
    *   **Output Zone**: Dedicated toolbar for result actions (View, Export, Copy).

2.  **Visual Style: Modern Academic (现代学术风)**:
    *   **Color Palette**: Minimalist white/grey background to reduce eye strain. Use brand color (e.g., #1677ff) sparingly for accents/actions.
    *   **Typography**: High readability, increased line-height (1.8), clear hierarchy.
    *   **Components**: Card-based design with soft shadows, rounded corners (12px-16px).

3.  **Interaction Design**:
    *   **Micro-interactions**: Hover states for secondary actions to reduce clutter.
    *   **Feedback**: Clear loading states, progress indicators, and success messages.
    *   **Flow**: Logical left-to-right or top-to-bottom operation flow.

## Implementation Checklist

### 1. Structure Optimization
- [ ] Remove clutter from top-level control panels.
- [ ] Implement "Toolbar-per-Panel" architecture.
- [ ] Centralize primary action buttons (Translate/Stop).

### 2. Styling Upgrade
- [ ] Apply "Modern Academic" color scheme.
- [ ] Refine typography (font size, weight, line height).
- [ ] Enhance container styling (cards, shadows, borders).

### 3. Polishing
- [ ] Add empty states with illustrations/icons.
- [ ] Smooth transitions and animations.
- [ ] Ensure responsive behavior.
